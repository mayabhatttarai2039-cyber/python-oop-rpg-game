# Object-Oriented RPG Battle Engine with CSV Database
A terminal-based Role-Playing-Game (RPG) engine built from scratch using python. This project serves as a portfolio piece demonstrating
Object-Oriented Programming (OOP) architectures and flat-file text
database integration.
## 🚀 Core Features & Concepts used
* **Class Blueprints (OOP): **Built custom templates (`player` and `Enemy`) using the `__init__` constructor method to manage distinct, independent statistics for separate game characters.
* **Class Methods (@class_method): ** Utilized a custom class method to read raw text from a file, parse the data fields, and dynamically manufacture a functional character object at runtime.
* **State Persistence (CSV Integration): ** created data streams using python's built-in `csv` module to automatically save character progress (`Name`, `Health`, `Gold`) to an external spreadsheet file upon victory.
* **Automated Battle Loop: ** Programmed a conditional `while` loop utilizing class Boolean checks (`is_alive()`) to execute automatic combat rounds until a character's health drops to zero.
* **Random Damage Variance: ** Integrated the standard `random` module to calculate unpredictable combat values and dynamic gold awards for each match.

## 📦 Project Structure 
* `rpg.py` - The primary code script containing the class structures, calculation methods, and main game loop execution.
* `save_data.csv` - The comma-separated database file generated by the program to hold the player's saved statistics
## ⚔️ Execution Instructions
Open a terminal window inside the project directory and run:
```bash
python rpg.py
```
